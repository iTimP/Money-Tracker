# สมุดบัญชีรายวัน

เว็บแอปจัดการรายรับ-รายจ่ายรายวัน พร้อมปฏิทินย้อนหลังและเมนูเงินเก็บ (ไฟล์เดียว ไม่ต้องติดตั้งอะไร)

## ฟีเจอร์
- บันทึกรายรับ/รายจ่าย เลือกวันที่จากปฏิทินและดูรายงานรายวัน
- หมวดรายจ่าย: อาหาร, ค่าโทรศัพท์, รายการผ่อน, ค่าน้ำมันรถ, อื่นๆ
- หมวดรายรับ: เงินเดือน, รายได้เสริม, อื่นๆ
- เมนูเงินเก็บ: เป้าหมายการออม ฝาก/ถอน และประวัติ

## ข้อมูลเก็บที่ไหน
เก็บใน localStorage ของเบราว์เซอร์ จึงไม่ซิงค์ข้ามเครื่อง และจะหายถ้าล้างข้อมูลเบราว์เซอร์

## ใช้งานในเครื่อง
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้ทันที

## เผยแพร่ด้วย GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
2. ไปที่ Settings > Pages แล้วเลือก Source เป็น **GitHub Actions**
3. push ไปที่ branch `main` ระบบจะเผยแพร่ให้อัตโนมัติ ลิงก์จะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`
